# Role-play procedure

Rehearsal: the agent plays the decision-maker; the user rehearses the
live conversation out loud or in text. Score the delivery against the
script, not against the floor (which the model never sees).

## Setup

- Pick the decision-maker from `references/counterparties.md`,
  usually the direct manager. Stay in character until the user says
  stop.
- Set the scene in one line ("you are in the review meeting you
  booked"), then let the user open.
- Pick the two likeliest objections for this case from the script's
  objection list, and hold one surprise the user did not script
  (top of band, a scope-not-level counter, a timing deflection).

## Playing the counterparty

- Push back realistically: a manager deflects, asks for evidence,
  cites budget, or offers a smaller shape. Do not fold on the first
  ask, and do not stonewall past what the case supports.
- React to what the user actually says, not to the script. A strong
  delivery earns movement; a weak one earns polite deflection.
- Never give away information the user could not know: no invented
  budget numbers, no "the band is really X", no commitments the
  scenario does not support.
- Keep it human and warm-ish. Managers in these conversations
  deflect more than they attack.

## Scoring the delivery

After each run, score the user against the script. One line per
item, pass or miss, then one fix per miss:

1. Opened relationally, named the purpose without apologizing.
2. Stated the precise ask or the climbing range, not a vague "more".
3. Gave the numbered reasons from the impact file.
4. Offered the equal options instead of dropping to a lower number.
5. Answered each objection without inventing facts and without
   conceding past the ladder step.
6. Closed asking for writing or a dated next step.

Score strictly. A smooth delivery that skipped the ask is a miss on
item 2, not a pass. Never score against the floor: the user wins the
run by following the script, not by holding some hidden line.

## Coaching loop

- Name the weakest segment and replay just that segment once.
- Two clean passes ends rehearsal. So does the user saying done.
- If the user wants the hard path, run the denial: the answer is no,
  and the rehearsal target becomes playbook move 11 (milestones in
  writing, a dated check-in).

## After rehearsal

- Update the script with the phrasing that scored best.
- Remind the user: the numbers are fixed. If the real conversation
  offers something below the script, they note it and debrief, they
  do not re-negotiate the plan live.
