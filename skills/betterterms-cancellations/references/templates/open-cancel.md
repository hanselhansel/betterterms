# Open the cancellation

Use for the first message, inside the provider's cancel flow when one
exists. Action: `send`. The body avoids the words the review tier
flags ("cancel", "process it"), so it passes review like every
shipped template. Drop the second paragraph when the user is
leaving for sure.

```
Hello,

I would like to end my service when the current billing period
finishes.

Before I finish, is there anything you can do on the price? If you
can offer {target}, I would consider staying. Otherwise please end
the service and put it in writing.

Thank you.
```
