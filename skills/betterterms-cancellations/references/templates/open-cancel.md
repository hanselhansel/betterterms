# Open the cancellation

Use for the first message, inside the provider's cancel flow when one
exists. Action: `send`; the cancellation wording returns
`needs_approval`, which is expected. Drop the second paragraph when
the user is leaving for sure.

```
Hello,

I would like to cancel my service when the current billing period
ends.

Before I finish, is there anything you can do on the price? If you
can offer {target}, I would consider staying. Otherwise please
process the cancellation and confirm it in writing.

Thank you.
```
