# Template: ask for the final terms in writing

Use when: the call landed on revised terms and the user needs the
updated offer in writing before deciding. Nothing counts until it
is written.

Draft fields:

- `action`: `send`
- `offer`: null
- `claims`: empty

```text
Subject: Updated offer in writing

Hi <name>,

Thank you for working through the package with me today. When you
can, please send the updated offer in writing: base, sign-on,
equity, level, start date, and the other terms we discussed.

I will review it and reply by <date>.

Best,
```

Notes:

- This message asks for the written record; it accepts nothing.
  Accept and sign are separate actions that always need the user's
  explicit approval.
- Name the components so nothing agreed on the call gets lost.
