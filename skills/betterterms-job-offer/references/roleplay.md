# Role-play and scoring

Rehearse the live call before the user has it. You play the
counterparty; the user plays themselves with the script in hand.
Score the delivery against the script after each round.

## Setup

- Pick the counterparty from `counterparties.md` (a recruiter by
  default). Give them a goal: close at the written offer.
- Load the five objections from the script. Run them in order of
  likelihood for this counterparty.
- Tell the user the rules: you stay in character until they say
  "pause" or the round ends. You are firm but fair, never hostile.

## Rounds

1. The ask: opening line, precise ask, reasons. Push back once with
   the likeliest objection, then let the user land the close.
2. Pressure: run two or three objections (current-comp probe, fixed
   band, locked budget, deadline pressure, "we do not negotiate"),
   escalating only after the user answers the earlier one.
3. Edge cases the user flagged: an exploding deadline, a silence, a
   flattery deflection ("you are our top candidate anyway").

Three to five exchanges is a rep. Keep each round short.

## Playing the counterparty

- Be realistic. A recruiter deflects, cites bands and budget, and
  asks for a fast answer. They do not cave in one line, and they do
  not threaten.
- Reward a good move with softening ("let me see what I can do"),
  not an instant yes.
- If the user concedes past their ladder, states the walk-away
  number, or invents a competing offer, stay in character. Let the
  scoring name it afterward.

## Scoring rubric

After each round, score the user's delivery against the script:
2 points for clean, 1 for partial, 0 for missed.

| Line | What clean looks like |
|---|---|
| Opening | Warm, names excitement, frames both-sides |
| Precise ask | One figure or a target-up range from the plan |
| Reasons | Two or three, each tied to a plan fact |
| Options | Offered two or three equal package shapes |
| Objection answers | Used the scripted answers, adapted, stayed warm |
| Concessions | Each move smaller than the last, each with a reason |
| Close | Asked for the revised offer in writing by a date |
| Guardrails | No floor, no never_disclose items, no invented offers |

Then give one thing that worked, one thing to fix, and a re-run of
the weakest beat. Update `plan.yaml` if the rehearsal surfaces a
better option shape.

## Debrief after the real call

Capture what was offered and the amounts stated (they become the
`amounts` list behind `{quote:n}`), update `plan.yaml`, and draft
the follow-up email from `templates/follow-up-recap.md`. Gate the
draft; the user sends the final words.
