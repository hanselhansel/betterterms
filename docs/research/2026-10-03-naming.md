# Naming the negotiation toolkit (2026-10-03)

Checks: GitHub repo search by stars, npm and PyPI lookups, official Claude plugin marketplace (315 plugins), GitHub code search for plugin manifests, web search. USPTO not searched. Run a knockout search before commercial launch.

## "haggle" assessment

**Connotation.** Dictionary.com: "to bargain in a petty, quibbling, and often contentious manner." US and UK readers hear market stalls and car lots. Fine for bills and refunds. For a raise it reads as squabbling with your boss. In Indian, Singaporean and Malaysian English, "bargain" is the everyday market verb and "haggle" carries the same stall image. In face-sensitive workplaces it reads worse.

**Crowding.**
- Haggle: AI Negotiation Coach (iOS) covers raises, salary, cars, rent. Direct overlap.
- Cleo "Haggle It" negotiates rent, bills, interest rates.
- Haggler (Shopify AI price negotiation). haggl.app (car-price agent, waitlist).
- lunchpaillola/haggle-skills, an agent-skills repo created 2026-09-26.
- An AI negotiation startup already renamed from Haggle to Counterwell.
- npm `haggle` and PyPI `haggle` are taken (unrelated packages).

**Plugin collision.** `hanselhansel/haggle` is free. No `haggle` in the official Claude marketplace. One third-party marketplace.json uses the name (0 stars). No Codex manifests. Plugins are namespaced `name@marketplace`, so a technical clash is unlikely. The risk is search confusion.

**Verdict: drop it as the umbrella. Keep it as a skill verb inside the kit.** `/askmore:haggle` for bills reads well. `/haggle:salary` does not.

## Slash-command feel

- `/askmore:intake`, `/askmore:bills`, `/askmore:salary`. Reads as a sentence. 7 characters. Best.
- `/betterterms:api-pricing` is clear. 11 characters.
- `/counteroffer:salary` is strong. `/counteroffer:refund` is a stretch. 12 characters.
- `/haggle:promotion` reads petty. `/dealkit:promotion` reads oddly.

## Top 3

1. **askmore**: "Your agent asks for more, so you don't have to." Covers raises, refunds, retention offers and API discounts. Short and verb-first, like gstack.
2. **betterterms**: "Better terms on every bill, plan and offer." The most professional option. Safest for salary and promotion.
3. **counteroffer**: "Never take the first number." Sharpest for job offers. Check distance from Counterwell first.
