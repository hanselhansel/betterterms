# NOTES-lane (R8)

- Root `plugin.json` is generated, so the required `skills` key was
  added in `scripts/_lib/gen_agent_plugins.py` and the file was
  regenerated by `scripts/bump-version 0.10.0` (which also stamped
  `.claude-plugin/plugin.json` and `.codex-plugin/plugin.json`).
- `tests/test_build_hosts.py` asserted `skills` is a banned manifest
  field. That test encoded the pre-R8 contract; it now allows
  `skills`, asserts it equals `./skills/`, and still bans `hooks`,
  `mcpServers` and `commands`.
- `mod-tests` runs `node --test` with `cwd=mod` (not `node --test
  mod`): on Node 24 the directory argument is treated as one test
  file and fails. `mod-validate` wraps both claude commands in
  `script(1)` when stdout is not a TTY (`script -q /dev/null` on
  macOS, `script -qec` elsewhere), and reports `SKIP` when `claude`
  is absent.
